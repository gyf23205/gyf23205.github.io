This work develops a unified framework for anomaly detection, classification, and root cause analysis in dynamic systems. A Joint-Embedding Predictive Architecture (JEPA) world model embeds the system dynamics in a latent space, improving accuracy and interpretability. The framework is evaluated on a high-fidelity NVIDIA Isaac Sim dataset of extreme lunar environments and rover fault models, and is applied to runtime monitoring in Hyundai–Kia's lunar rover project, reaching an area under the receiver operating characteristic curve (AUC-ROC) above 93% and an F1 score above 90%.
